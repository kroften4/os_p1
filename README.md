# Usage
## build
build
```sh
make
```
clean
```sh
make clean
```

## run
```sh
bin/main add --image disk.img --key "0987654321" src include Makefile
bin/main list --image disk.img
bin/main get --image disk.img --key "0987654321" src/buf.c
```
